Basis Desktop — Scope and Limitations

This is a Windows desktop beta. Review assumptions, source documents and calculations independently before using results in an investment decision. Automated tests cover defined cases; they do not certify every underwriting structure.

  • The desktop and web editions share the same financial implementation and native schema v1. Their saved libraries are separate. Move editable models using .basiscre backups; installing desktop does not migrate browser data automatically.
  • Save a .basiscre portfolio backup before upgrades or recovery. Local rolling snapshots can help recover the desktop workspace, but they are stored on the same device and do not protect against device loss. Restoring a workspace snapshot restores its whole library.
  • Model and workspace files are not encrypted by Basis. Optional API-key storage in Windows Credential Manager does not encrypt the financial data.
  • Packaged PDF and Excel readers support local document handling. Unsupported workbook features, external resources and ambiguous source data can still require manual review or entry.
  • AI extraction requires a supported provider account, network access and your own API key. Provider charges are separate. Review fields and citations before Apply; a successful connection test is not an accuracy test.
  • Report workbooks contain calculated values and assumptions. They are not editable model backups or guaranteed third-party report-template equivalents. Use .basiscre to reopen models or the separate XL4ADW template workflow for supported input fields.
  • The initial desktop edition has no cloud synchronization, shared editing or automatic update installation. Cloudflare Access continues to protect the web deployment and does not provide desktop login.
  • Windows installers may be unsigned and show unknown-publisher or SmartScreen warnings. A built installer is not a publisher signature. Consult the release validation record and complete native Windows save, recovery, offline import and upgrade checks on your intended device.
