Basis Beta — Data and Privacy

The standalone beta saves property models and recovery drafts in this browser's storage. It does not provide cloud synchronization. Anyone using the same browser profile may be able to access those files. Download .basiscre backups regularly, especially before changing browsers or site addresses.

Documents and AI

Uploading and reading a document happens locally. Choosing Extract sends selected document text or images, filenames, and limited property context (such as analysis start, area, and existing tenants used for matching) to your selected OpenAI or Anthropic API account. Host integrations, when present, use the host's service. Review your provider's terms and data settings before sending confidential information.

API keys stay in memory for this tab and are not written to property files or browser storage. Browser extensions, compromised scripts, and other users of an unlocked device can still present risks. Only use a trusted device. Your API account pays usage charges. Test AI Connection sends a short fixed message, with no document or property content.

AI results are proposals. Review values and source evidence before Apply. A successful connection test or matched document total does not verify the accuracy of extracted facts.

Other requests

Optional spreadsheet and PDF features load versioned, integrity-checked libraries from the SheetJS CDN and cdnjs. Those services and the hosting provider can receive ordinary connection metadata, such as IP address. Basis does not add analytics or automatic model/error uploads. The hosting operator must disclose any additional logging or tracking it enables.

Backups, deletion, and feedback

Exports contain the data you choose to export. Recovery drafts are separate from the saved library; use File → Recover drafts to manage them. Clearing site data removes this browser's library, preferences, and recovery drafts but cannot erase files you downloaded or data already sent to a provider. Export a backup before clearing site data.

Send feedback through the private channel provided in your beta invitation. Include the release version, browser, steps, and a synthetic example. Do not include API keys, leases, rent rolls, tenant personal data, or unredacted screenshots in public issues.
