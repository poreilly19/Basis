# Development provenance note

Basis Studio evolved from an earlier independent commercial real-estate modeling prototype. Earlier versions used commercial third-party product behavior, examples, documentation, and screenshots as references. The existence of independently authored code is not sufficient to establish a historical clean-room process; do not claim one.

Previous iterations v3 through v6 focused on modernizing layouts, mobile navigation, and original task-based workflows while maintaining underwriting math. This v7 milestone introduces a proposed `.basiscre` native ZIP/JSON model format and save/open UI, a migration-aware reader, basic archive safety limits, documentation and test fixtures.

Product-specific labels in the distributed application and historical documentation have been replaced with neutral workbook terminology. This editing does not change the development history or establish clean-room provenance, originality, or legal clearance. The distributed historical feature inventory identifies its neutralized text explicitly.

This file is an honest process memo, not verification of the provenance of every line of source or a legal opinion. Keep source snapshots, commit logs, test results, and third-party attribution in the actual Git repository as the project proceeds.
