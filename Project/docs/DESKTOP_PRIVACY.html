Basis Desktop — Data and Privacy

Basis Desktop saves the model library to ordinary files in this Windows user's application data directory. The library is separate from the website's browser storage. Preferences and recovery drafts also use the desktop WebView's local storage. Desktop does not provide cloud synchronization, team accounts or shared editing.

Model and workspace files are not encrypted by Basis. Windows account permissions and your device's security protect local access. Anyone who can access your Windows account or copy these files may be able to read the model data. Use a trusted device and keep independent .basiscre portfolio backups.

Documents and AI

Selecting and reading a document happens locally. The desktop package includes the supported PDF and spreadsheet runtimes, so reading a supported document does not require downloading those libraries.

Choosing Extract sends selected document text or images, filenames, and limited property context, such as analysis start, area and existing tenants used for matching, to your selected OpenAI or Anthropic API account. Review your provider's terms and data settings before sending confidential information. AI extraction needs network access and your provider account pays usage charges.

API keys remain in memory unless you explicitly choose to remember a key on this device. Remembered keys use Windows Credential Manager and are excluded from model files, workspace snapshots and support exports. Remembering a key does not encrypt the model library. An unlocked or compromised device can still expose credentials and data.

Test AI Connection sends a short fixed message without document or property content. A successful connection test or matching document total does not verify extraction accuracy. Review proposed fields and their source evidence before Apply.

Backups, deletion and updates

Rolling workspace backups are local recovery copies in the application data directory, not independent off-device backups. A workspace snapshot may contain every portfolio saved in this desktop workspace. Exported .basiscre files and report workbooks contain the data you choose to export; protect them as you would the source documents.

Deleting application data can remove saved models, preferences, recovery drafts and local backups. Deleting a model from the current workspace does not erase earlier backups, exported files or data already sent to an AI provider. Manage remembered API keys separately from model files. Export backups before upgrades, recovery or uninstalling.

Other requests and feedback

Basis does not add analytics or automatic model/error uploads. The initial desktop edition does not automatically download updates. Installing or updating Windows components and manually downloading a release can contact their respective services. AI requests contact the selected provider.

Cloudflare Access protects the hosted website; it does not protect local desktop copies or synchronize their storage. For public bug reports, include the version, Windows version, reproduction steps and a synthetic example. Do not post API keys, leases, rent rolls, tenant personal data or unredacted screenshots.
