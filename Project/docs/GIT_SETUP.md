# Optional: use GitHub + Codex Cloud

Keep the repository **private** while legal and third-party license reviews remain open.

1. Extract this project on your Windows computer and open a terminal in the extracted folder.
2. If you have Git installed, run:

   ```powershell
   git init
   git add .
   git commit -m "Import Basis Studio v7 with .basiscre format"
   ```

3. Create an empty **private** repository on GitHub and push the local repository using the GitHub-provided `git remote add origin ...` and `git push -u origin ...` commands.
4. Open Codex, connect the private GitHub repository in your Codex Cloud environment (if available), and start with `CODEX_START_HERE.md`.

Alternatively, skip GitHub and open the extracted local folder directly with Codex on desktop, or use the CLI / VS Code extension. Codex conversations do not automatically inherit this ChatGPT conversation: the repository handoff documents preserve scope and technical decisions.
