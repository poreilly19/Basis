Basis Beta — Scope

This is a beta candidate for controlled testing. Review assumptions, source documents, and calculations independently before using results in an investment decision. Automated tests cover defined cases; they do not certify every underwriting structure.

  • Save a .basiscre backup before testing an upgrade. Storage belongs to the browser profile and site address; a different domain does not inherit your library.
  • Report workbooks contain calculated values and assumptions. They are not editable model backups or guaranteed third-party report-template equivalents. Use .basiscre to restore models, or the separate XL4ADW template workflow for supported input fields.
  • AI extraction requires your own supported account/model, browser API access, and field review. Unsupported or ambiguous lease terms may require manual entry.
  • The standalone beta has no team accounts, cloud synchronization, or shared model editing. Invite-only access must be enforced by the hosting service.
  • Desktop browser smoke tests do not establish native Safari, iOS, or Windows compatibility. Consult the release validation record and complete your intended device's acceptance checks.
  • A public open-source license, source/asset distribution decisions, and broader analyst validation remain separate release decisions.

Read Data and Privacy and the release notes supplied with your beta invitation.
