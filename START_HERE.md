# Start Basis Studio v0.7.27

1. Download **Code → Download ZIP** and extract the ZIP.
2. Open the extracted **Project** folder.
3. On Windows, double-click **Start Basis.cmd**. On macOS/Linux, run
   `python3 scripts/start-basis.py` from that folder.
4. Open **http://127.0.0.1:8765/** and leave the server window running.

Python 3.10 or newer is required. No restoration script or Base64 decoding is
needed; the source files and sample models are directly usable.

See [the repository guide](README.md) for development and hosting, or
[the application guide](Project/README.md) for workflows and known limitations.
The older v7.9 encoded upload is preserved in Git history.
